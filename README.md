# ![팔레트 아이콘](docs/icon48.png) HSU(한성대) 팔레트

한성대학교 e-class 화면의 테마를 원하는 대로 바꾸고 저장하는 크롬 확장 프로그램

![version](https://img.shields.io/badge/Chrome%20Web%20Store-v.1.1.3-red?style=flat&logo=chrome%20web%20store&logoColor=red&labelColor=1f2937)![manifest](https://img.shields.io/badge/Licenses-Apache%202.0-orange?style=flat&logoColor=orange&labelColor=1f2937)    

</div>

## 주요 기능

| 기능            | 설명                                                   |
| --------------- | ------------------------------------------------------ |
| 🎨 영역별 색     | 상단바·배너·메뉴·카드·버튼 등 영역을 눌러 색 바꾸기    |
| 🖥️ 화면별 테마   | 메인 화면과 강의 페이지에 테마를 따로 적용             |
| 🎁 추천 프리셋   | 미드나잇·포레스트·라벤더 등 30가지 테마를 바로 적용    |
| 💾 내 프리셋     | 지금 테마를 저장해 두고 언제든 다시 불러오기           |
| 💉 스포이드      | 화면에서 색을 골라 쓰고 자주 쓰는 색은 즐겨찾기        |
| 🔤 글자색        | 배경에 맞춰 자동으로, 또는 흰색·검정·회색으로 지정     |
| ✏️ 폰트          | 기본·Pretendard·주아·나눔스퀘어라운드 중에서 선택      |
| ▶️ 영상 창       | 강의 영상 창의 상단바도 테마 색에 맞춰 표시            |

> [!TIP]
> 테마는 크롬 계정에 저장되어 다른 PC에서도 그대로 이어진다.



## 설치

[Chrome Web Store](https://chromewebstore.google.com/detail/clhpdcfmifehbciceddjcgiimnjflgad?utm_source=item-share-cb) 에서 설치한다.



## 직접 설치

1. 이 저장소에서 **Code → Download ZIP**으로 받아 압축을 푼다.
2. 크롬 주소창에 `chrome://extensions`를 입력하고 오른쪽 위 **개발자 모드**를 켠다.
3. **압축해제된 확장 프로그램을 로드합니다**를 눌러 압축 푼 폴더를 선택한다.



## 기술 스택

- 순수 JavaScript + CSS
- Chrome Extension Manifest V3
- 글꼴: Pretendard, 주아(Jua), 나눔스퀘어라운드 (SIL OFL 1.1)
- 아이콘: Lucide (ISC)
